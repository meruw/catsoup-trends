# Contributing

CATsoup Trends is currently an architecture-only project. There are no build or test commands to run yet.

Read the [architecture](docs/ARCHITECTURE.md) and [PoC scope](docs/POC.md) before proposing a change.

## Proposing changes

- Use an issue to discuss feature scope or architectural changes before implementation.
- Keep pull requests focused and describe the problem, resulting behavior, and validation.
- Write repository documentation, code, and identifiers in English.
- Clearly distinguish proposed behavior from implemented functionality.
- Add dependencies only when a concrete requirement justifies them.

For documentation changes, check relative links and Markdown formatting. Future implementation changes should include tests for relevant behavior and failures; document executable checks when those tools exist.

## Sensitive data

Do not submit credentials, access tokens, personal account details, private research, or downloaded source media. Use synthetic or explicitly redistributable examples.

Personal agent instructions and local development settings are not project documentation and should remain untracked.
